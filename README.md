# Packet demo V3

Clickable front-end prototype of the Packet platform: commissioning a site, mapping raw tags to the Canonical Asset Model, the model itself across sites, analytics written once against the model, and fleet rollout.

**Prototype with simulated data.** No live systems, no customer data. Nothing is written to any device.

## How to view

Open the GitHub Pages link for this repository. Built for a laptop or projector at 1440 px wide; each screen fits one window. Not designed for phones.

Use **Next** in the footer (or the right arrow key) to follow the five-step tour, or jump between screens from the icon rail. **Reset** in the footer clears all state.

## Screens

1. Commission · Cimarron Flats Solar
2. Map & Contextualize · Chisholm Ridge Solar + Storage
